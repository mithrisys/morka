name: morka-design
description: Design accessible desktop app workflows.
---

Design around the action that brings someone to the app. In an empty notebook, put an editable first note in reach. In a gallery, give the image the largest area. Use the starter type, spacing, focus and color defaults or the project's existing visual system. Use headings and labels that convey information, native buttons and inputs, visible keyboard focus and sufficient contrast. Keep the primary action reachable at narrow widths, with long content and at text zoom. Design useful empty, busy, success and recoverable error states. Prevent duplicate submits. Honor a user's reference, existing layout and design tokens.

For a new screen or changed path, add or update the preview scenario with an expectation for the visible result. Morka exercises the scenario on the rendered page and handles screenshot review after the editing turn. Consider clipped controls, confusing hierarchy, cramped text, missing focus and unnecessary copy when designing the screen. For a color or spacing tweak, retain the current linked stylesheet and control IDs.
