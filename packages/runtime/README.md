# @morka/runtime

The desktop runtime for Morka apps. It runs the app's Node.js backend and opens its desktop window in Electron.

From a generated app repository, use Node.js 24 or later and npm:

```sh
npm ci
npm start
```

The project's start script invokes `morka run`. Run `npm run install:app` to add the app to the current user's application menu.

[Morka documentation](https://github.com/mithrisys/morka#readme)
